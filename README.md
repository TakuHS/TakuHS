## 👤 About Me

<!-- TODO: お名前・所属・連絡先（任意）-->
個人開発でWebサービスを企画から運用まで一人で作り切るのが好きなフルスタックエンジニアです。
フロントの3D表現からリアルタイム通信、サーバーレス基盤、生成AI統合まで横断的に扱います。

### ✅ できること
- 🖥 **フルスタック開発** — フロント・バックエンド・インフラを一気通貫で構築
- ⚡ **リアルタイム通信** — マルチプレイヤー対戦などの双方向通信
- 🎮 **3D / インタラクティブ表現** — Three.js によるリッチUI
- 🤖 **生成AI統合** — LLM API を組み込んだプロダクト開発
- ☁️ **サーバーレス / エッジ** — Cloudflare・Supabase・AWS での構築運用

### 🧭 これまで
- リアルタイム対戦ゲームプラットフォームの個人開発（設計〜実装〜運用）
- 生成AIを活用したWebアプリケーション
- Webサービス・ツール群の企画・開発
- サーバーレス基盤やゲーム開発（Unity）の経験
